# Simple Interest Calculator

A Bash script-based calculator that computes simple interest from user input.

## About
This project calculates simple interest using the formula:

    Simple Interest = (Principal × Rate × Time) / 100

## Input Fields
- **Principal**: the initial amount of money
- **Rate of Interest**: annual interest rate (%)
- **Time Period**: duration in years

## Usage
1. Make the script executable: `chmod +x simple-interest.sh`
2. Run it: `./simple-interest.sh`
3. Enter the principal, rate of interest, and time period when prompted.

## Example
Principal = 1000, Rate = 5%, Time = 2 years → Simple Interest = 100
